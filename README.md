# MAISON VÊTU (Luxe Brand)

A premium fashion e-commerce platform built with the PERN stack (PostgreSQL, Express, React, Node.js).

## Live Demo
🚀 **[View Live on Vercel](https://luxe-brand.vercel.app/)** *(Note: Replace with your exact Vercel URL if different)*

## Features
- **Modern UI/UX**: Premium design aesthetics without external CSS frameworks.
- **Authentication**: JWT-based secure authentication.
- **Admin Portal**: Full dashboard for managing products, users, and themes.
- **PostgreSQL / Supabase**: High-performance database connected via Prisma ORM.

## Tech Stack
- Frontend: React 18, Vite, Context API
- Backend: Node.js, Express.js
- Database: PostgreSQL (Supabase), Prisma ORM
